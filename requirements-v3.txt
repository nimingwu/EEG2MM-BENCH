# --- 复现性注意事项 -----------------------------------------------------
# 跨机器**无法逐位复现** GPU fp32 结果：同一 checkpoint、同一输入，在两台机器上
# 编码器输出的 max|Δ| ≈ 1.9e-3（TF32 开启时；均值 4.9e-5）。
# 已实测该量级对 2AFC 指标的影响为 7.6e-5，可忽略。
# 因此 v3 的验收标准是「指标一致（容差见文末实测结论）」，不是「逐位相同」。
# TF32 保持 PyTorch 默认（开启）——关掉反而使差异增大到 8.2e-3。

# --- 验收容差（2026-10-21 实测）-------------------------------------------
# v3 在同一台机器上是**逐位确定**的：同一命令重复运行，embedding / 投影预测 / 8 个
# 指标全部 0.00e+00 差异。
#
# 与 v2 已存结果的差异全部来自跨机器浮点漂移，且被链路逐级放大：
#     embedding 8.5e-04  ->  投影预测 7.8e-03（约 9x）  ->  inception 1.2e-02
# 五个编码器在 ThingsEEG sub-01 上的最坏差异：
#     enigma_cnn 6.1e-04 | labram 2.6e-03 | reve 2.8e-03 | atm_s 4.9e-03 | luna 1.2e-02
# 因此 verify 的容差取 2e-2，而不是最初设想的 1e-3。这不是重构质量问题。
